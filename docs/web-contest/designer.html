01El arnés

Una tarea entra.
Nueve criterios salen.

Nueve agentes especializados abordan el mismo problema desde ángulos que no se solapan. idu-pi reparte el trabajo, mantiene un contexto compartido y evita que una sola voz decida por todas.

regla 01

El reparto no es aleatorio: cada tarea activa el peso adecuado de cada agente.

02Pruebas ocultas

Lo que el agente
nunca vio.

Antes de aceptar una respuesta, idu-pi la ejecuta contra una suite que el agente nunca vio: contratos, casos borde, invariantes y presupuestos de rendimiento. Lo que falla no llega al veredicto.

03El motor

Tres capas.
Un veredicto.

El arbitraje no es una votación. Es una pila de responsabilidades: primero se comprueba, después se pesa el desacuerdo y solo al final se sintetiza.

Cada afirmación se ancla a una prueba ejecutada. Sin traza, no hay punto.
